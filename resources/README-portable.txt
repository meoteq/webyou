WebYou 1.0.0 — portable edition
================================

WebYou is a friendly editor for learning to build websites. It runs from any
folder: no installer, no administrator rights, no internet connection needed.

Quick start
-----------
1. Unpack the whole archive into a folder, for example C:\WebYou.
2. Run WebYou.exe.
3. Pick a template or open an existing folder with your website.
4. Edit the code on the left and watch the preview on the right.

PHP 8.4 is included, so .php files work immediately. Settings and recent
projects are stored in the "data" folder next to WebYou.exe. If that folder is
not writable, WebYou uses %APPDATA%\webyou instead.

First launch on Windows
-----------------------
The build is not code-signed, so Windows SmartScreen may show a warning.
Choose "More info" and then "Run anyway".

If PHP does not start on a clean Windows installation, install the Microsoft
Visual C++ 2015-2022 x64 runtime:
https://aka.ms/vs/17/release/vc_redist.x64.exe

The interface switches between Russian and English in Settings. The theme can
be light, dark, or follow the system.

WebYou 1.0.0 — переносимая версия
=================================

WebYou — дружелюбный редактор для первых шагов в веб-разработке. Работает из
любой папки: без установки, прав администратора и интернета.

Быстрый старт
-------------
1. Распакуйте весь архив в папку, например C:\WebYou.
2. Запустите WebYou.exe.
3. Выберите шаблон или откройте папку с готовым сайтом.
4. Редактируйте код слева и смотрите результат справа.

PHP 8.4 уже внутри, поэтому файлы .php работают сразу. Настройки и недавние
проекты хранятся в папке "data" рядом с WebYou.exe. Если папка недоступна для
записи, используется %APPDATA%\webyou.

Первый запуск в Windows
-----------------------
Сборка не подписана, поэтому SmartScreen может показать предупреждение.
Нажмите «Подробнее», затем «Выполнить в любом случае».

Если на чистой Windows PHP не запускается, установите среду выполнения
Microsoft Visual C++ 2015-2022 x64:
https://aka.ms/vs/17/release/vc_redist.x64.exe

Язык интерфейса переключается между русским и английским в настройках. Тема
может быть светлой, тёмной или как в системе.
